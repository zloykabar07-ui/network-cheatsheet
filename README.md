# Сетевая шпаргалка

## 1. Базовые сетевые определения

- **IP-адрес** — логический 32-битный адрес устройства в сети (IPv4). Состоит из адреса сети и адреса хоста [citation:5].
- **Маска подсети** — 32-битное число с непрерывной последовательностью единиц в старших разрядах; показывает, какая часть IP-адреса относится к сети, а какая — к хосту [citation:5].
- **Шлюз по умолчанию** — устройство (обычно роутер), через которое пакет уходит в другие сети, если адрес назначения не принадлежит локальной подсети [citation:5].
- **DNS** — система доменных имён, преобразует имена сайтов в IP-адреса.
- **DHCP** — протокол автоматической выдачи IP-адресов, маски, шлюза и DNS.

## 2. HTTP и HTTPS

| | HTTP | HTTPS |
|---|---|---|
| Шифрование | Нет, данные передаются открытым текстом | Есть (SSL/TLS) |
| Порт по умолчанию | 80 | 443 |
| Защита от перехвата | Нет | Да |
| Браузер | Помечает как «не защищено» | Показывает замок |

**Вывод:** HTTPS — это HTTP, работающий поверх шифрованного канала TLS/SSL. Пароли и платёжные данные передавайте только по HTTPS [citation:3][citation:7].

## 3. Простейшие команды диагностики

### Windows (cmd / PowerShell)
- `ipconfig` — показать IP-адрес, маску, шлюз.
- `ipconfig /all` — подробно, включая MAC и DNS.
- `ping 8.8.8.8` — проверить доступность узла.
- `ping google.com` — проверить работу DNS.
- `tracert google.com` — трассировка маршрута.
- `nslookup google.com` — проверить DNS-запрос.

### Linux / macOS
- `ip addr` или `ifconfig` — адреса интерфейсов.
- `ip route` — таблица маршрутизации (шлюз).
- `ping -c 4 8.8.8.8`
- `traceroute google.com`
- `dig google.com`

## 4. Типовые проблемы и что проверять

| Симптом | Что проверить |
|---|---|
| Нет интернета, но локальная сеть есть | Шлюз, DNS |
| `ping 8.8.8.8` работает, сайты не открываются | DNS |
| `ping` по IP не работает | Кабель/Wi-Fi, маска, шлюз |
| Медленно / потери | `ping -t` (Windows) или `ping` в цикле |
